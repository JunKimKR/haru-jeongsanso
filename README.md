# 하루 정산소

좌우로 넘기는 하루 카드와, 한 달이 끝나면 자동으로 발행되는 월간 정산서.

빌드 도구도 의존성도 없는 **단일 HTML 파일**입니다. `index.html` 하나만 열면 그대로 동작하고,
GitHub Actions로 GitHub Pages에 배포됩니다.

---

## 기능

### 휴대폰 앱으로 설치

GitHub Pages처럼 HTTPS 주소로 배포하면 안드로이드 Chrome에서 상단의 **설치** 버튼이 나타납니다.
버튼을 누르면 홈 화면과 앱 목록에 `하루 정산소`가 추가되고, 브라우저 주소창 없이 독립 앱처럼
실행됩니다. 설치 후에는 오프라인에서도 최근 화면과 기록을 사용할 수 있습니다.

- 안드로이드: 앱 안의 `설치` 버튼 또는 Chrome 메뉴 → `앱 설치`
- 아이폰·아이패드: Safari 공유 버튼 → `홈 화면에 추가`
- 설치 버튼은 이미 설치됐거나 설치를 지원하지 않는 브라우저에서는 자동으로 숨겨집니다.

### 하루

- 카드 한 장이 하루. 원통(실린더) 위에 놓인 것처럼 **좌우로 돌아가며** 넘어갑니다.
- 카드 맨 위에 날짜 · 요일이 찍히고, 오늘이면 `오늘` 도장, 다른 날은 `D+2` / `D-3`으로 표시됩니다.
- 할 일 체크리스트 + 자유 메모, 하단에 완료 진행바.
- **자정이 지나면 자동으로 다음 날 카드로 넘어갑니다.** (15초 주기 확인 + 탭 복귀 시 확인)
- 이동 방법: 스와이프 / 드래그, `←` `→` 키, `Home` 키(오늘), 하단 주간 스트립, 우측 상단 `오늘` 버튼.
- **모바일 키보드 대응** — 입력란을 누르면 주간 스트립을 접고 카드가 남은 화면을 전부 차지하며,
  `visualViewport` 로 실제 보이는 높이(`--vh`)를 재서 지금 쓰는 줄이 키보드 위에 오도록 카드 안을 스크롤합니다.
  뷰포트 메타에 `interactive-widget=resizes-content` 를 넣어 안드로이드에서는 레이아웃 자체가 줄어듭니다.

### 정산 (월간 정리)

한 달치 기록을 영수증 모양의 **정산서**로 자동 발행합니다.

| 항목 | 설명 |
| --- | --- |
| 명세 | 등록한 할 일 · 완료 · 완료율 · 기록한 날 · 최장 연속 |
| 정산 | `기록한 날 × 기준 건수` 대비 실제 완료를 비교해 **환급 +N건 / 추징 −N건** |
| 등급 도장 | 완료율과 출석률로 우수 / 양호 / 성실 / 백지 |
| 잉크 달력 | 완료 건수만큼 잉크가 진해지는 한 달 히트맵 |
| 요일별 완료 | 가장 부지런한 요일을 붉게 강조 |
| 자주 쓴 말 | 할 일·메모에서 반복된 단어 Top 5 (조사 제거) |
| 이월 항목 | 못 끝낸 할 일 목록 → 버튼 하나로 오늘 카드에 이월 |
| 보관함 | 지난 달들이 미니 그래프가 달린 영수증 조각으로 쌓임 |
| 내보내기 | 정산서를 `.md` 파일로 저장 |

`기준 조정`에서 하루 기준 건수(기본 3건)를 바꾸면 정산 결과가 즉시 다시 계산됩니다.

## 배포 (GitHub Actions)

1. 이 폴더를 그대로 새 저장소에 올립니다.

   ```bash
   git init -b main
   git add .
   git commit -m "하루 정산소 첫 커밋"
   git remote add origin https://github.com/<사용자명>/<저장소명>.git
   git push -u origin main
   ```

2. 저장소 **Settings → Pages → Build and deployment → Source** 를 **GitHub Actions** 로 바꿉니다.
   (이 한 단계만 하면 됩니다. 브랜치 선택이나 `gh-pages` 브랜치는 필요 없습니다.)

3. `main` 에 푸시할 때마다 [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml) 이 돌면서

   - `verify` — `scripts/check.mjs` 로 `index.html` 의 인라인 스크립트 문법, 필수 엘리먼트,
     태그 균형, 배경 흰색 여부를 검사합니다. 실패하면 배포하지 않습니다.
   - `deploy` — 커밋 SHA를 `__BUILD__` 자리에 넣어 서비스 워커 캐시를 갱신하고 Pages에 올립니다.

   배포 주소는 `https://<사용자명>.github.io/<저장소명>/` 입니다.
   Actions 탭의 `배포` 잡 요약에도 링크가 표시됩니다.

수동 실행은 Actions 탭 → `Deploy to GitHub Pages` → `Run workflow`.

## 데이터는 어디에 저장되나요

브라우저의 `localStorage` 에 `haruledger:m:YYYY-MM` 키로 **월 단위**로 저장됩니다.
서버도 계정도 없으니 기록은 그 브라우저 밖으로 나가지 않습니다. 기기 간에 자동으로 옮겨지지는 않습니다.

- 백업: 정산 탭의 `정산서 저장 (.md)`
- 초기화: 개발자 도구 콘솔에서
  ```js
  Object.keys(localStorage).filter(k => k.startsWith('haruledger:')).forEach(k => localStorage.removeItem(k));
  ```

> 이 저장소 버전은 `localStorage` 만 씁니다. Claude 아티팩트로 발행한 버전은 `window.claude.use("db")` 가
> 있으면 기기 간 동기화를 함께 쓰는데, 그 코드는 `window.claude` 가 없으면 조용히 건너뛰도록 되어 있어
> GitHub Pages에서도 같은 파일이 그대로 동작합니다.

## 직접 고치기

전부 `index.html` 안에 있습니다. 자주 만질 만한 값:

```css
.card{
  --cw: min(330px, 76vw);   /* 카드 너비 — 작게 할수록 옆 카드가 많이 보임 */
  --ch: min(500px, calc(100dvh - 205px)); /* 카드 높이 */
  --R:  calc(var(--cw) * 1.5); /* 원통 반지름 — 작을수록 카드끼리 가까워짐 */
  --th: 40deg;              /* 카드 하나당 회전 각도 */
}
:root{
  --accent:#23486B;         /* 잉크색 (체크·히트맵·막대) */
  --seal:#B03A2E;           /* 도장 붉은색 (오늘·추징·최고 요일) */
}
```

- 회전을 더 극적으로: `--th` 를 키우고 `--R` 도 함께 키웁니다.
  두 카드가 겹치지 않는 최소 반지름은 `--cw / 2 × cot(--th / 2)` 입니다.
- 애니메이션 속도: `.stage.animating .card` 의 `transition` 시간.
- 배경은 항상 흰색으로 고정되어 있습니다. `scripts/check.mjs` 가 다크 모드 재정의를 발견하면
  배포를 막습니다.

로컬에서 보려면 그냥 `index.html` 을 열거나:

```bash
python3 -m http.server 8000   # http://localhost:8000
```
